## التحميل والتثبيت

1. اقرأ صفحة التطبيق، واختر ملف APK المتوافق مع جهازك. Full وLite للشطرنج بديلان؛ ثبّت أحدهما.
2. افتح APK بعد تنزيله. قد يطلب أندرويد السماح بالتثبيت من المتصفح أو مدير الملفات.
3. امنح فقط الأذونات التي تحتاجها الميزة المختارة. راجع دليل الإعداد لكل برنامج.
4. قبل تحديث تطبيق يحتوي بيانات مهمة، احتفظ بنسخة احتياطية. يلزم نفس معرّف التطبيق والتوقيع للتحديث دون حذف البيانات.

معظم الحزم الحالية Debug منشورة كنسخ تجريبية، بينما Golan Safe Pro حزمة Release. لا يعني ذلك اعتماد Google Play أو اختبار كل هاتف وإصدار أندرويد. تتوفر تفاصيل النسخة والقيود وبصمات SHA-256 في صفحة Releases الخاصة بكل تطبيق.

## السورس الكامل

رابط ZIP في كل صف ينزّل أرشيف المشروع الكامل المجهز للنشر. فك الأرشيف واتبع تعليمات البناء داخله. أرشيفا GitHub التلقائيان «Source code» يخصان ملفات صفحة المستودع؛ استخدم أرشيف المصدر المسمّى `*-source.zip` في مرفقات الإصدار.

استُبعدت مفاتيح التوقيع الخاصة وبيانات المستخدم والنسخ الشخصية وسجلات الأجهزة. تبقى تراخيص المكونات الخارجية محفوظة، ويجب مراجعتها قبل إعادة الاستخدام أو إعادة التوزيع. إتاحة السورس للعامة لا تحل محل ترخيص صريح لكود المشروع.
