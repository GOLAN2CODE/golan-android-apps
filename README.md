## Download and install / التحميل والتثبيت

Open an application's **Releases** page, read its compatibility and known limitations, and download the APK under **Assets**. Android may request permission to install from your browser or file manager. Grant only the runtime permissions needed for the feature you choose.

افتح صفحة **Releases** للتطبيق، واقرأ التوافق والحدود، ثم حمّل APK من **Assets**. قد يطلب أندرويد السماح بالتثبيت من المتصفح أو مدير الملفات. فعّل فقط الأذونات اللازمة للميزات التي تختار استخدامها.

Preserve your backups before updating apps that store important data. Android updates require the same package identifier and signing identity. Several published packages are development Debug builds and are marked as previews; availability here does not imply Google Play approval or support for every device.

احتفظ بنسخة من بياناتك المهمة قبل التحديث. يتطلب التحديث نفس معرّف التطبيق والتوقيع. بعض الحزم نسخ تطوير Debug وموسومة كتجريبية؛ نشرها هنا لا يعني اعتماد Google Play أو اختبار جميع الأجهزة.

## Feedback / الملاحظات

Report reproducible problems through the relevant repository's **Issues**, including app version, Android version and clear steps. Remove personal messages, account credentials and private media from reports.

بلّغ عن المشاكل في **Issues** ضمن مستودع التطبيق، مع رقم النسخة وإصدار أندرويد وخطوات واضحة. احذف الرسائل الشخصية وبيانات الحسابات والوسائط الخاصة من البلاغ.
